Checked on 2026-11-21.

- Official Droppy nightly feed: <https://dl.getdroppy.app/app-releases/nightly/latest.json>.
- Installed host: **Droppy 16.3.0-beta.1** (build **16300001**).
- SDK checkout: **DroppyKit 1.22.0**, revision **c417d8a54cc45fb798b06b8a5b88dfa4761f5938** (`main`, also `v1.22.0`).
- The official public SDK repository exposes no nightly branch or tag. The website documents 1.23.0 APIs not yet in that repository; do not treat those docs as an available matching nightly SDK. This package uses the newest publicly available SDK, not an invented nightly pin.
- Installed Droppy Playground: **1.0.37**, build **10037**.

The local-path dependency in `Package.swift` uses that SDK checkout directly. `kit.minAPI` is **1.21.0** (for DroppyKit's flat-wash `DroppyWashPillButtonStyle` and `DroppyWashCircleButtonStyle`) and `minAppVersion` remains 15.3.0. No icon or surface changes are required. `clipboard-write` is declared for explicit Copy path / Copy settings actions; no clipboard history is read.

The back circle (`chevron.left`) is 40 × 40 points on the leading edge of the completed footer, matching the 40pt solo flat-wash pills so **+ New symlink** and **Show in Finder** share the exact same 146 × 40pt size and unified 13pt rounded typography (with **Name already exists** expanding to 188 × 40pt when shown alone) while **Show in Finder** stays anchored on the trailing edge and both file tiles remain 128 × 96pt inside the compact 364pt solo canvas (92pt tile gap on notch; 370pt unchanged on Dynamic Island). The paired shelf/home widget drops the top-left header in favor of two vertical System-Settings-style tiles with a blue active-step highlight, an animated green confirmation morph (**Create symlink** → **Created** → **Show in Finder**), and a circular `+` button to clear selections and start a new symlink without touching files on disk; settings/popover/playground buttons use native macOS `.bordered`/`.borderedProminent` controls. Loading indicators replace the tile icon in the center of both solo and paired tiles. Shared metrics budget the tiles, 40-point footer and host insets (164 points for the full active panel, 112 idle). No description/path row or selected-tile captions are shown; errors use the existing footer. **+ New symlink** clears both selections; **<** instead returns to the source and destination tiles with those selections preserved. Both leave the original file and created link untouched. Duplicate-name notices crossfade back into **Create symlink** after six visible seconds. Selections remain editable; retries revalidate and never replace existing items. Notice tasks stop on navigation, selection changes and deactivation.

The installed Droppy already matches the current nightly feed, so no app update is necessary. For a later nightly, use Droppy's Settings → About update controls and select the Nightly channel, then approve the app's update prompt. Install the local bundle through Settings → Store → Local droplets and approve that build if prompted; restart Droppy if an earlier Symlinker build is already loaded. Do not disable local-build approval globally for testing.
